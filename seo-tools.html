3. URL Slug Generator

Turn a heading or title into a clean, lowercase URL slug.

4. Robots.txt Generator

Create a basic robots.txt template. Check your site's setup before using it; robots.txt is not a security feature.

Only add paths you actually want crawlers to skip. Do not block CSS or JavaScript needed to render your pages.

5. FAQ Schema Generator

Generate JSON-LD FAQ markup for real questions and answers visible on your page.

Valid markup does not guarantee a rich result. Google limits FAQ rich results mainly to well-known government and health sites. Keep markup consistent with visible page content.

6. UTM Link Builder

Add campaign tracking parameters to a URL for analytics reporting.

Your tracked URL will appear here.

Use consistent lowercase campaign naming where possible. Do not put personal or confidential information in tracking parameters.
